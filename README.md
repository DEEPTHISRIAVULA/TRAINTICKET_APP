# 🚆 TRAINTICKET_APP

## 📌 Description

A menu-driven Train Ticket Booking Application developed using **C programming**. The application allows users to create accounts, sign in, reserve train tickets, cancel bookings, and view booking details.

It uses file handling to store user, train, and passenger information, ensuring that data persists even after the application is restarted.

## ✨ Features

* User Sign-up and Sign-in
* Train Ticket Reservation
* Ticket Cancellation
* View Booking Details
* File-based Data Storage
* Menu-driven User Interface
